# Four Hourseman

Static team-profile page presenting four collaborators, their roles, portraits, and social links. Built with HTML and CSS.

## Getting started

Run `python -m http.server 8000` here and open `http://localhost:8000/`. Serving from the repository root preserves the root-relative stylesheet path.
